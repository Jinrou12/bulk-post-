# FB AutoPoster Pro 🚀

A modern, responsive web app built for Facebook Pages & Groups auto-scheduling, bulk image uploading, AI Khmer marketing caption generation, and live Facebook feed preview.

## 🌟 Key Features

- **Bulk Photo Upload & Auto Split**: Drag & drop multiple images and auto-split into individual posts.
- **Auto-Scheduler Engine**: Interval-based scheduler (15m, 30m, 1h, 2h, 6h, 1d) with live countdown timers.
- **Facebook Feed Live Preview**: Multi-photo grid layout engine matching real Facebook feed styling.
- **✨ AI Khmer Marketing Assistant**: Generates formatted marketing copy with emojis, phone numbers, and hashtags.
- **💾 LocalStorage Session Persistence**: Automatically remembers App ID, Access Token, and Campaign state across page reloads.
- **🔑 Flexible FB Authentication**: Supports Graph API access tokens, Facebook SDK OAuth, and instant demo login.

## 🚀 Quick Start

1. Clone or download this repository.
2. Serve locally using Python or any static web server:
   ```bash
   python -m http.server 9090
   ```
3. Open `http://localhost:9090` in your web browser.

## 🛠️ Tech Stack

- HTML5 / CSS3 (Vanilla Dark Mode UI)
- JavaScript (ES6+)
- Facebook Graph API v20.0
- Lucide Icons
